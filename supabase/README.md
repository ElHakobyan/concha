# Бэкенд Perla на Supabase

Сайт остаётся на GitHub Pages, а заказы и подписчики сохраняются в бесплатной базе
Supabase (это PostgreSQL). О каждом новом заказе вам приходит письмо на почту.

| Файл | Что делает |
|---|---|
| `schema.sql` | Таблицы `orders` (заказы), `subscribers` (подписчики), `products` (цены) и две функции для сайта |
| `email.sql` | Письмо вам на почту о каждом новом заказе (по желанию) |
| `admin.sql` | Админка: каталог в базе, фото, остатки, тексты сайта, вход только для вас |
| `../config.js` | Адрес вашего проекта Supabase и публичный ключ |

## Настройка (один раз, ~15 минут)

### 1. Создать проект
1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub.
2. **New project**: название `concha`, придумайте пароль базы (сохраните его), регион ближе к Армении, например **Central EU (Frankfurt)**.
3. Подождите 1–2 минуты, пока проект создаётся.

### 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Скопируйте весь текст из `supabase/schema.sql`, вставьте и нажмите **Run**.
3. Должно появиться *Success. No rows returned*. Слева в **Table Editor** появятся `orders`, `products`, `subscribers`.

### 3. Подключить сайт
1. Слева **Project Settings** → **Data API**: скопируйте **Project URL** (вида `https://abcd.supabase.co`).
2. **Project Settings** → **API Keys**: скопируйте ключ **publishable** (`sb_publishable_...`) или, если его нет, **anon public**.
3. Вставьте оба значения в `config.js` в корне сайта и сохраните.

Ключ **secret / service_role** никогда не вставляйте на сайт: он даёт полный доступ к базе.

### 4. Письма о новых заказах
1. Зайдите на [resend.com](https://resend.com) → **Sign up**. Регистрируйтесь **той почтой, на которую хотите получать заказы** (без своего домена Resend отправляет письма только на неё).
2. Подтвердите почту, затем слева **API Keys** → **Create API Key** → название `concha`, права **Sending access** → **Add**. Скопируйте ключ вида `re_...` (он показывается один раз).
3. В Supabase: **SQL Editor** → **New query** → вставьте текст из `supabase/email.sql`,
   замените `ВСТАВЬТЕ_КЛЮЧ_RESEND` и `ВСТАВЬТЕ_ВАШУ_ПОЧТУ` своими значениями → **Run**.
   Ключ сохранится в зашифрованном хранилище Supabase (Vault), в коде сайта его нет.

Письмо придёт от `onboarding@resend.dev` с темой «Новый заказ №…». Если покупатель оставил email,
кнопка «Ответить» в письме сразу напишет ему. Первое письмо может попасть в «Спам»: отметьте его «Не спам».
Бесплатно до 3000 писем в месяц.

### 5. Админка
1. **Authentication** → **Users** → **Add user** → **Create new user**: впишите свою почту и пароль,
   поставьте галочку **Auto Confirm User** → **Create user**. Этими почтой и паролем вы будете входить в админку.
2. **Authentication** → **Sign In / Providers** (или **Settings**): выключите **Allow new users to sign up**,
   чтобы никто другой не мог зарегистрироваться. (Даже если кто-то зарегистрируется, в админку он не попадёт.)
3. **SQL Editor** → **New query** → вставьте текст из `supabase/admin.sql`. В самом конце файла замените
   `ВСТАВЬТЕ_ВАШУ_ПОЧТУ` на почту из шага 1 → **Run**.
4. Чтобы ссылка «Забыли пароль?» работала: **Authentication** → **URL Configuration** → **Site URL**:
   адрес вашего сайта, например `https://elhakobyan.github.io/concha/admin/`.
5. Откройте `ваш-сайт/admin/` и войдите.

После этого сайт берёт товары из базы. Все 36 текущих украшений перенесены туда автоматически.

### 6. Проверить
Положите товар в корзину на сайте, оформите заказ. Он появится в **Table Editor → orders**,
а на почту придёт письмо.

## Админка (`ваш-сайт/admin/`)
- **Товары**: добавить, изменить, скрыть или удалить. Фото, цена, категория, название и материал
  на трёх языках, отметки «Хит», «Новинка», «Подарок». Изменения видны на сайте сразу после обновления страницы.
- **В наличии**: если указать число, сайт не даст заказать больше, а после заказа остаток уменьшится сам.
  При 0 на сайте появится «Нет в наличии». Пустое поле значит «не считать». Если отменить заказ,
  товары вернутся на склад.
- **Заказы**: все заказы с контактами. Статус: Новый → Подтверждён → Отправлен → Выполнен (или Отменён).
- **Клиенты**: все, кто зарегистрировался на сайте (имя, фамилия, email, телефон), поиск и «Скачать список (CSV)».
- **Подписчики**: список и кнопка «Скачать список (CSV)».
- **Тексты сайта**: любой текст сайта на армянском, русском и английском. «Вернуть исходный» отменяет правку.

Всё то же самое видно и в панели Supabase (**Table Editor**), но в админке удобнее.

## Аккаунты покупателей
Регистрация и вход на сайте работают через Supabase Auth (`accounts.sql`):
email + пароль, подтверждение email по письму, «Забыли пароль?» с письмом для нового пароля.
Пароли хранит и проверяет Supabase, на сайте и в админке их не видно. Имя, фамилия и телефон
лежат в таблице `profiles`: покупатель видит только свою строку, администратор видит всех.

Что настроить в панели Supabase один раз:
1. **Authentication → URL Configuration**: в **Site URL** адрес сайта, в **Redirect URLs** он же со звёздочкой
   (например `https://perla-jewerly.loan/**`). Иначе ссылки из писем будут вести не туда.
2. Встроенная почта Supabase бесплатная, но отправляет всего несколько писем в час. Когда покупателей станет больше,
   подключите свой SMTP, например Resend (**Authentication → Emails → SMTP Settings**).

## Безопасность коротко
- Посетители сайта не могут читать заказы или подписчиков: включён Row Level Security,
  а сайт может только вызвать функции `place_order` и `subscribe` и прочитать включённые товары и тексты.
- Менять что-либо может только пользователь из таблицы `admins`. Это проверяет сама база,
  поэтому страница `/admin` открыта всем, но без вашего пароля она бесполезна.
- Чтобы добавить ещё одного администратора: создайте ему пользователя (шаг 5.1) и в **SQL Editor** выполните
  `insert into admins (user_id) select id from auth.users where email = 'его@почта';`
- Сумму заказа считает сервер по таблице `products`, поэтому цену в браузере подменить нельзя.
- Бесплатный проект Supabase «засыпает» после 7 дней без запросов. Если это случится,
  зайдите в панель и нажмите **Restore** (данные не теряются).
