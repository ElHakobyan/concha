# Бэкенд Concha на Supabase

Сайт остаётся на GitHub Pages, а заказы и подписчики сохраняются в бесплатной базе
Supabase (это PostgreSQL). О каждом новом заказе вам приходит письмо на почту.

| Файл | Что делает |
|---|---|
| `schema.sql` | Таблицы `orders` (заказы), `subscribers` (подписчики), `products` (цены) и две функции для сайта |
| `email.sql` | Письмо вам на почту о каждом новом заказе (по желанию) |
| `../config.js` | Адрес вашего проекта Supabase и публичный ключ |

## Настройка (один раз, ~15 минут)

### 1. Создать проект
1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub.
2. **New project**: название `concha`, придумайте пароль базы (сохраните его), регион ближе к Армении, например **Central EU (Frankfurt)**.
3. Подождите 1–2 минуты, пока проект создаётся.

### 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Скопируйте весь текст из `supabase/schema.sql`, вставьте и нажмите **Run**.
3. Должно появиться *Success. No rows returned*. Слева в **Table Editor** появятся `orders`, `products`, `subscribers`.

### 3. Подключить сайт
1. Слева **Project Settings** → **Data API**: скопируйте **Project URL** (вида `https://abcd.supabase.co`).
2. **Project Settings** → **API Keys**: скопируйте ключ **publishable** (`sb_publishable_...`) или, если его нет, **anon public**.
3. Вставьте оба значения в `config.js` в корне сайта и сохраните.

Ключ **secret / service_role** никогда не вставляйте на сайт: он даёт полный доступ к базе.

### 4. Письма о новых заказах
1. Зайдите на [resend.com](https://resend.com) → **Sign up**. Регистрируйтесь **той почтой, на которую хотите получать заказы** (без своего домена Resend отправляет письма только на неё).
2. Подтвердите почту, затем слева **API Keys** → **Create API Key** → название `concha`, права **Sending access** → **Add**. Скопируйте ключ вида `re_...` (он показывается один раз).
3. В Supabase: **SQL Editor** → **New query** → вставьте текст из `supabase/email.sql`,
   замените `ВСТАВЬТЕ_КЛЮЧ_RESEND` и `ВСТАВЬТЕ_ВАШУ_ПОЧТУ` своими значениями → **Run**.
   Ключ сохранится в зашифрованном хранилище Supabase (Vault), в коде сайта его нет.

Письмо придёт от `onboarding@resend.dev` с темой «Новый заказ №…». Если покупатель оставил email,
кнопка «Ответить» в письме сразу напишет ему. Первое письмо может попасть в «Спам»: отметьте его «Не спам».
Бесплатно до 3000 писем в месяц.

### 5. Проверить
Положите товар в корзину на сайте, оформите заказ. Он появится в **Table Editor → orders**,
а на почту придёт письмо.

## Как работать с заказами
- **Table Editor → orders**: все заказы. Колонку `status` можно менять:
  `new` → `confirmed` → `shipped` → `done` (или `cancelled`).
- **Table Editor → subscribers**: подписчики; кнопка **Export → CSV** выгружает список.
- **Table Editor → products**: цены, по которым сервер считает сумму заказа. Если меняете цену
  в `script.js`, поменяйте её и здесь. `active = false` запрещает заказывать товар.
  Новый товар нужно добавить и в `script.js`, и сюда (иначе заказ с ним не пройдёт).

## Безопасность коротко
- Посетители сайта не могут читать заказы или подписчиков: включён Row Level Security,
  а сайт может только вызвать функции `place_order` и `subscribe`.
- Сумму заказа считает сервер по таблице `products`, поэтому цену в браузере подменить нельзя.
- Бесплатный проект Supabase «засыпает» после 7 дней без запросов. Если это случится,
  зайдите в панель и нажмите **Restore** (данные не теряются).
